# GitHub publication steps

1. Review `README.md` and `docs/case_study.md` as the public narrative.
2. Confirm that the chart is your current export and that it displays at full size.
3. Use this package as the contents of the chosen repository. Extract the ZIP first; uploading only the ZIP prevents GitHub from showing the README and folders normally.
4. If updating an existing repository, compare its contents first and preserve any older project work you want to retain. This package does not change the repository by itself.
5. After upload, open the repository and check the README image, case-study links, and reproduction instructions.
6. Add the published repository URL to the portfolio and use that link in the LinkedIn introduction.

Suggested repository description: Historical bank outreach prioritization: logistic regression versus random selection and a prior-success rule, with an earlier-to-later evaluation and conditional pilot recommendation.
